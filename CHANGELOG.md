# ComfyBattleText Changelog

## 0.1 Beta – 28.09.2026

- Initial WoW Forever foundation.
- Added Incoming, Outgoing and Notifications scrolling areas.
- Added damage, healing, misses/avoidance, interrupts and dispels.
- Added optional own-pet damage.
- Added critical scaling, compact numbers, spell names/icons and school colors.
- Added optional nameplate combat text.
- Added draggable scroll-area anchors and test mode.
- Added Comfy Suite profiles, shared Settings/Info layout and native Blizzard AddOns registration.
